UI Framework Spec

AI System Prompt Instructions

UI Design specification matrix. Ready to inject into Cursor .cursorrules, Copilot, or Claude.

[UI DESIGN SYSTEM CONSTRAINTS]:

1. GEOMETRY: All elements must have explicit 0px border-radius (`border-radius: 0px !important`). Strictly no rounded edges, pill badges, or soft radii.

2. CONTRAST & READABILITY: All text labels, category subheaders, and helper copy must meet minimum 4.5:1 (WCAG AA/AAA). Muted grey labels must use bold weights and dark slate tones (e.g. `text-neutral-700 dark:text-neutral-300`), not washed-out greys.

3. ACCENT PROTOCOL: Deloitte Green (#86BC25) is strictly reserved as an intentional anchor dot, positive delta marker, active tab rule, or focus indicator. Use `#628f14` for small green text on light backgrounds for guaranteed contrast ratio.

4. DARK MODE SYMMETRY: Canvas: `bg-[#EFEFF2] dark:bg-[#09090b]`. Cards: `bg-white dark:bg-neutral-900`. Borders: `border-neutral-300 dark:border-neutral-700`. Primary text: `text-neutral-950 dark:text-white`.

5. BUSINESS & AGENTIC ARCHITECTURE: Use structured definition lists (`

`) for entity metadata dossiers, facet filter toolbars with removable chips, modal confirmation overlays with clear impact notes, embedded AI insight cards (with confidence rating, rationale bullets, and dual accept/override actions), and chronological audit streams with actor tags (`AGENT`, `USER`, `GATEWAY`).
